dsh-pure · PE 使用说明（2026-11-03 深夜 v3）
============================================

【这一版改了什么】
  Pale Moon 缺少 AbortSignal.any / throwIfAborted，导致连不上后端。
  已在 dsh-client-connection 的客户端文件里注入 polyfill 补上这些 API。
  所以现在理论上可以真正连上，新建会话/工作区/模型设置应该能用了。

【怎么试】
  1. 双击 G:\dsh-pure\start-dsh.cmd
  2. 浏览器会自动打开（这次直接 spawn，不再经过 start）
  3. 看左下角：还显示「重新连接中...」就是没成，消失就是成了

【如果还是连不上】
  按 F12 打开错误控制台，把第一屏报错拍给我。
  重点看还有没有 xxx is not a function 这种缺 API 的错。

【已经确认可行的事】
  - node v22.20.0 在 PE 里跑得起来（fs/net/http/crypto 全过）
  - 内核能起、能打印 token、能响应 HTTP、界面能渲染
  - 这个 PE 没有 ping / ipconfig / timeout，启动器已全部改成 node 实现

【不要做的事】
  × 不要去 G:\dsh-pure 以外的目录乱点
  × 不要删包里的文件
  × 不要改分辨率
