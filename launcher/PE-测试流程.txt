============================================
dsh-pure · PE 使用说明（2026-11-03 v6）
============================================

【v6 新增：shell 通道】
  PE 里没有 PowerShell，AI 之前只能读写文件、不能执行命令。
  现在包里带了一个 pwsh.exe 垫片（用 Node SEA 做的，81.7MB），
  它把 dsh 发来的命令转给 PE 自带的 cmd.exe 执行。
  dsh 启动时会打印 [dsh] pwsh: G:\dsh-pure\pwsh\pwsh.exe

  ★ 注意：它是 cmd 语义，不是真 PowerShell。
    dir / cd / echo / copy / del / type 这些能用，
    Get-ChildItem、| 管道对象、$env:XXX 这类 PowerShell 语法不适用。

【怎么用】
  1. 双击 G:\dsh-pure\start-dsh.cmd
  2. 看启动输出三行都对：
       [dsh] credentials: loaded from ...apikey.txt
       [dsh] pwsh: G:\dsh-pure\pwsh\pwsh.exe
       [dsh] url: http://127.0.0.1:3080/?token=...
  3. 浏览器里发消息，让 AI 跑个 dir 试试

【不要再做的事】
  × 不要删 pwsh 目录（删了 AI 就只能读写文件了）
  × 不要动 G:\dsh-pure 以外的目录

【已确认可行】
  - node v22.20.0 / dsh 内核 / 界面 / 会话 / 消息 / 联网 全部正常
  - Pale Moon 缺的 AbortSignal.any 已 polyfill
  - shell 走 cmd 垫片，命令能真正执行
